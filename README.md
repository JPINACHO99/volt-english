# Volt English ⚡

Installable English trainer (PWA) for levels **B1–C2**: speaking, listening, reading, writing, grammar and vocabulary, organised by topic.

**Open the app:** https://jpinacho99.github.io/volt-english/

- Works on desktop and mobile; install it from the browser menu ("Install app" / "Add to Home Screen").
- Everything is free: built-in checker (local rules + LanguageTool public API) and, optionally, an AI examiner with your own free Gemini key (Settings).
- Progress is stored only in the browser of each device.
- Listening audio is generated with `tools/build_assets.py` (Kokoro TTS, Apache-2.0). Word-frequency list: google-10000-english.
